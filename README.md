# LocalTV — твой домашний телеканал 📺

Включаешь — и сериалы идут сами, как по телевизору: серия за серией, на весь
экран, круглые сутки. Ничего не надо выбирать и включать каждый раз. Программа сама
помнит, на чём ты остановился в каждом сериале.

**Ставить ничего не нужно** — всё уже внутри: скачал, распаковал, запустил.

## Как начать

1. Скачай `LocalTV.zip` во вкладке **[Releases](../../releases)** и распакуй папку
   куда удобно (например, на диск `C:`).
2. Запусти файл **`TvShowsPlayer.App.exe`** из этой папки.
3. Откроется окно настроек. Нажми **«Выбрать…»** и укажи папку, где лежат сериалы.
4. Нажми **«Запустить канал»** — начнётся показ на весь экран.

Дальше программа живёт **значком у часов** (справа внизу экрана, рядом с временем).
Щёлкни по нему правой кнопкой мыши — там пауза, громкость, следующая серия и настройки.

### Как разложить сериалы

Внутри общей папки — отдельная папка на каждый сериал, а в ней файлы серий:

```
Сериалы\
   Чип и Дейл\
      Серия 01.mkv
      Серия 02.mkv
   Утиные истории\
      Сезон 1\
         S01E01.mkv
```

Названия могут быть любыми — программа сама разберётся с порядком серий. Если вдруг
серии пойдут не по порядку, в настройках есть вкладка **«Проверка серий»**: она
покажет, как программа поняла нумерацию.

## Что умеет

- **Показывает по очереди.** Несколько серий одного сериала, потом следующего —
  и так по кругу, без конца.
- **Помнит место в каждом сериале.** Добавил или убрал сериал — остальные
  не сбиваются.
- **Сам замечает новые сериалы.** Скачал новый — он появится в эфире сам.
  Недокачанные серии не берёт: ждёт, пока файл дозагрузится.
- **Управление, не отрываясь от дел** — значок у часов и сочетания клавиш,
  которые работают из любой программы.
- **«Без звука»** — одна кнопка, чтобы приглушить канал на время разговора,
  не останавливая показ.
- **Свой порядок сериалов** — перетаскивай мышью; галочкой можно временно
  убрать сериал из эфира.
- **Русская озвучка** выбирается автоматически, громкость выравнивается между
  сериями.
- **Включается вместе с компьютером**, если поставить галочку в настройках.

## Клавиши

| Клавиши | Что делает |
|---|---|
| Ctrl+Alt+Пробел | пауза / продолжить |
| Ctrl+Alt+= / − | громче / тише |
| Ctrl+Alt+→ | следующая серия |
| Ctrl+Alt+M | без звука |
| Ctrl+Alt+R | починить звук, если отстаёт от картинки |
| Ctrl+Alt+N | показать, что идёт сейчас |

Если такие сочетания уже заняты другой программой, в настройках можно выбрать другие
или выключить клавиши совсем.

## Настройки и просмотренное

Хранятся отдельно от программы — в папке `%LOCALAPPDATA%\LocalTV`. Поэтому новая
версия не стирает ни настройки, ни память о просмотренном: просто распакуй её поверх.

Если что-то пошло не так, там же лежит файл `localtv-app.log` — в нём программа
пишет, что случилось.

## Если раньше пользовался версией под именем JETIX

Программа называлась JETIX и была переименована. При первом запуске новой версии всё
переезжает само — настройки и просмотренное сохраняются. Старый пульт от версии на
AutoHotkey новым каналом больше не управляет: пользуйся значком у часов и клавишами.

## Для разработчиков

Порт рабочего скриптового набора (mpv + Python + AutoHotkey) в приложение
на .NET 8 / Avalonia. Ядро покрыто тестами (165), Windows-only.

```
dotnet test TvShowsPlayer.sln
dotnet publish src/TvShowsPlayer.App -c Release -r win-x64 --self-contained -o publish/LocalTV
```

Плеер — [mpv](https://mpv.io), управляется по JSON-IPC; экранная графика и закладка
просмотра — Lua-скрипты внутри mpv. Настройки и состояние канала лежат в
`%LOCALAPPDATA%\LocalTV`, режим (dev/prod) переключается переменной `LOCALTV_MODE`.
