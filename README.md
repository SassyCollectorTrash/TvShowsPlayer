# LocalTV — личный мультканал 📺

Твои мультсериалы как настоящий **ТВ-канал 24/7**: карусель серий по всем сериалам,
полный экран, автопереход, пульт в трее и глобальные горячие клавиши. Внутри уже
всё нужное — **mpv в комплекте, ставить ничего не надо** (даже .NET).

> Порт рабочего скриптового кита (mpv + Python + AutoHotkey) в полноценное
> .NET 8 / Avalonia приложение.

## Скачать

Готовый билд — во вкладке **[Releases](../../releases)**: скачай `LocalTV.zip`,
распакуй, запусти `TvShowsPlayer.App.exe`. Больше ничего устанавливать не нужно.

## Как пользоваться

1. Запусти `TvShowsPlayer.App.exe` — значок появится в трее (у часов).
2. Правый клик по значку → **«Настройки…»**.
3. **Пути → «Обзор…»** → укажи свою папку с мультфильмами.
   Структура: `<папка>\Название сериала\...файлы серий (.mkv/.mp4/.avi/...)`
   (сезоны можно раскладывать по подпапкам «Сезон 1» и т.п.).
4. По желанию: аудио-устройство, порядок сериалов, исключения → **«Сохранить»**.
5. Перезапусти (трей → «Выход» → снова запусти) — канал соберётся и пойдёт на полный экран.

## Возможности

- **Карусель** серий с нахлёстом — каждый сериал по очереди, бесшовный цикл.
- **Менеджер плейлиста**: порядок сериалов перетаскиванием, галочки «в канале»
  (исключения), «Сейчас в эфире» + очередь «Далее», переход по двойному клику.
- **Новые сериалы подхватываются сами** — канал периодически проверяет библиотеку.
  Недокачанные серии в эфир не попадают: файл должен полежать без изменений.
- **Прогресс по каждому сериалу** сохраняется; добавил/убрал сериал — остальные не сбиваются.
- **Диагностика библиотеки**: видно, по какой схеме распознан номер серии и где сезон
  в имени файла спорит с папкой — если серии идут не в том порядке.
- **Пульт в трее** и **глобальные хоткеи** (пауза, громкость, следующая серия/сериал,
  мьют «режим созвона», ресинк звука, «что идёт сейчас»).
- **Русская озвучка по языку** + подхват внешней озвучки (.mka), выравнивание громкости.
- **Автозапуск** при входе в систему (галка в настройках).
- **Проверка обновлений**: версия видна в настройках внизу, новая — кнопкой «Скачать».
- Настройки и прогресс — в `%LOCALAPPDATA%\LocalTV`, поэтому **обновление их не затирает**.

## Обновление с версий под именем JETIX

Приложение раньше называлось JETIX. При первом запуске новой версии данные
переезжают сами: папка `%LOCALAPPDATA%\Jetix` → `%LOCALAPPDATA%\LocalTV`, файл
прогресса `jetix-channel-state.json` → `localtv-channel-state.json`. **Прогресс
просмотра сохраняется**; если перенос не удался (папка занята), канал продолжит
работать со старой папкой и повторит перенос при следующем запуске.

Заодно сменились внутренние имена: IPC-канал (`localtvmpv`), сообщения скриптам
(`localtv-*`) и переменная режима (`LOCALTV_MODE`). Поэтому пульт от старого
скриптового кита (AutoHotkey) на новый канал больше не действует — управляйте
через трей и горячие клавиши приложения.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+Alt+Space | пауза / пуск |
| Ctrl+Alt+= / − | громче / тише |
| Ctrl+Alt+→ | следующая серия |
| Ctrl+Alt+M | режим созвона (мьют) |
| Ctrl+Alt+R | пересинхронизировать звук |
| Ctrl+Alt+N | плашка «сейчас в эфире» |

Набор модификаторов можно сменить в настройках, если комбинации занимает другая
программа, или выключить хоткеи целиком.

## Сборка из исходников

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download). mpv положи рядом в `mpv\mpv.exe`
или укажи путь в настройках.

```
dotnet test TvShowsPlayer.sln
dotnet publish src/TvShowsPlayer.App -c Release -r win-x64 --self-contained -o publish/LocalTV
```
